# 叙事间 · 小说创作工作台

一个轻量的中文小说规划工作台，可整理作品定位、故事梗概、人物、世界设定、剧情线、关键节点、伏笔与章节大纲。内置“长夜来信”通用示例，所有内容均可编辑，并可导入、导出草稿。

## 本地运行

这是一个无需构建步骤的静态网页。可在本目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。也可以将仓库根目录部署到 GitHub Pages。

## 数据与隐私

工作台在浏览器中编辑内容，不会自动上传到服务器。请使用“保存草稿”导出 JSON 文件，并妥善保管备份。仓库中的示例故事仅用于演示工作台功能。
